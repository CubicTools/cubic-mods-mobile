# Cubic Mods Mobile

Cubic Mods Mobile is an Android app that adds extra features to Cubic Castles on your phone. No root needed, and the game itself isn't changed: you keep playing the normal Cubic Castles from the Play Store.

## What it adds

- **Vend card**: tap a vending machine and see what it sells and how the prices compare.
- **Market search**: find who's selling an item and go straight to their machine.
- **Dressing Room**: try on clothes, pets and cars before you buy them.
- **Block finder**: finds fossils (or any blocks you pick) in the realm.
- **Multi-break / multi-build**
- **Friends, Profile, Perks, Quests, Cubit Store** windows, opened from the game's own Menu button.
- **Realm splash**, custom block picture, chat commands (`/w`, `/r`, `/ban`, `/trust`, `/search` and more).

## Download

Get `cubic-mods-android-<version>.apk` from the [Releases](../../releases) page.

## Install

https://youtu.be/CER2sC78x2k

1. Open the downloaded APK on your phone. If Android asks, allow your browser or file app to install unknown apps.
2. Open **Cubic Mods** and follow the setup screen:
   - **Allow display over other apps** so it can draw over the game.
   - **Allow usage access** so it knows when Cubic Castles is open.
   - Tap **Start** and allow the VPN. It only carries Cubic Castles' own connection; nothing else on your phone goes through it.
3. Open Cubic Castles and log in (if it was already open, log in again).
4. In a realm, tap the game's **Menu** button (top left). The pink bubble is the Dressing Room, and the **cubic mods** bubble opens the rest.

With **Turn on with Cubic Castles** switched on, Cubic Mods starts by itself whenever you open the game.

## Updates

Tap **Check for updates** in the Cubic Mods app. It downloads the new version and Android asks you to install it.

## Tips

- If a feature stops working after a Cubic Castles update, check for a Cubic Mods update.
- Nothing showing in the game? Make sure the VPN key icon is in your status bar, then log in again.
